    Part 1
Testing the tree functionality: 
To test the functionality of the decision tree model you run the decision_tree.py file. 
This will fit the model to a sklearn make_classification dataset. 
It will then print the accuracy and a human readable interpretation of the model. 


    Part 2 & 3 
To run the rest of the project you run the run_experiments.ipynb file. 
This will train the model on the churn dataset. Do the model selection and print the performance 
of the best model. 

It wil also do the feature importance parts of the assignment. 

churn-data.csv must be in the same folder as the notebook
